## 11 - Kata

Le candidat peut utiliser le langage de programmation qu’il souhaite, ou expliquer, étape par étape (en utilisant une approche pseudo-code), comment réaliser l'exercice.

A - Écrivez un code qui vérifie si un nombre est pair ou impair: 1. Écrivez un code qui demande à l'utilisateur de saisir un nombre. 2. Ensuite, le code doit déterminer si ce nombre est pair ou impair et afficher le résultat dans la console.

B - Écrivez un code qui invite l'utilisateur à entrer son prénom. Le code doit renvoyer : "Bonjour, [Prénom] ! Heureux de faire votre connaissance."

C - Écrire un programme qui calcule la somme des nombres dans une liste et affiche uniquement les nombres supérieurs à un seuil donné. 1. Crée une liste de nombres entiers (par exemple, [4, 12, 7, 19, 3, 8]). 2. Calcule et affiche la somme de tous les nombres de la liste. 3. Affiche uniquement les nombres de la liste qui sont supérieurs à 10.
